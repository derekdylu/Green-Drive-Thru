# Security Policy

## Supported version

Security fixes are applied to the latest revision of the `main` branch. Historical commits and third-party forks are not supported.

## Report a vulnerability

Please use [GitHub's private vulnerability reporting form](https://github.com/derekdylu/Green-Drive-Thru/security/advisories/new). Include the affected page or component, impact, reproduction conditions, and any suggested mitigation.

Do not open a public issue or include a live credential, personal data, or a weaponized proof of concept in a public discussion. If a credential may be exposed, revoke or rotate it before sharing further details.
